# Learn composition from approved complete figures

This reference distils a paired study of the author's clinical-agent and spatial
resource figures: approved complete renders, the native SVG generation scripts,
and public revision messages. The transferable choices concern composition and
reading. The projects' scientific images, private session records and result
numbers are not bundled here.

## What made the approved work stronger

- **One dominant scientific scene.** A mechanism region shows a real case from
  input to a specific result. The original image, source excerpt or measured
  coordinates occupies real space. An agent or repository icon names an actor;
  it does not replace evidence. A later quantitative row tests the illustrated
  mechanism at scale.
- **Alignment carries the argument.** A source image hangs below its corresponding
  event; an answer sits beside the rubric it was scored against; a measured
  result sits beneath the relevant condition. This visual correspondence removes
  repeated prose and long diagonal connectors.
- **Texture comes from observations.** One mark per actual study, model, query or
  cell provides detail. An individual mark remains recognizable at print size.
  Density is not the count of text-filled cells, labels, panels or arrows.
- **Short titles establish hierarchy.** Ordinary black sans-serif lettering,
  a modestly emphasized panel letter/title, consistent body size, and quiet axes
  make the important scene visible. Respect a user's requested regular weight;
  do not use colored typography or oversized result numbers to force emphasis.
- **The charts have different jobs.** A cumulative curve explains search depth;
  a point comparison shows which method performs better; a component matrix
  shows which parts affect which tasks; a repeat-run plot shows variation.
  Different chart types can share font, scale conventions and mark sizes.

## When the dense redraw still looks poor

An inspected spatial-resource redraw preserved real data and passed automated
geometry checks, yet the author rejected it. It scattered small pictures, long
ROI connectors and crowded numeric tables across a tall page. The inference is
specific: adding genuine data did not correct weak visual hierarchy.

For this kind of failure, redraw the composition before adjusting colors:

1. Select the main real material and give it a continuous reading region.
2. Place corresponding views on shared baselines. For a multiscale image, use
   full tissue → the registered field → the same local boundaries/molecules.
   A box on the source plus an adjacent enlargement usually needs less connecting
   geometry than a distant inset. Preserve distinct expression readouts when
   their scales differ; do not blend them into a decorative composite.
3. Replace a table-like heatmap when the question is numerical comparison.
   Raw query dots on a shared axis convey order and gaps immediately. Group by
   difficulty when useful; keep all actual observations or explicitly state a
   display subset. Preserve original labels and numeric tables in supporting
   material.
4. Keep a matrix when both dimensions carry the question, such as component
   effects across tasks. A sparse effect-dot matrix or compact numeric matrix
   can work; choose it deliberately, with a truthful scale and visible null and
   positive results. Do not remove inconvenient values for a cleaner pattern.
5. Use a coherent gallery band when the purpose is technology comparison. Choose
   clear representative real images; equal display slots do not require warping
   images or inventing a common scale bar.
6. Judge the whole render beside an approved complete figure. Look for its
   dominant region, reading order, relationships, text burden and overall
   proportions. Then inspect details. A collage of pleasing isolated panels
   can still fail as a complete figure.

## Specific patterns that can be reused

| Evidence | Useful composition | Detail that must remain truthful |
|---|---|---|
| One example plus population evidence | Large mechanism region above a short row of quantitative panels | Example identity and corresponding experiment |
| Intent-conditioned search | Intent/actor → ranked candidate observations → shared questions and contrasting real cases | Inputs are metadata/file evidence; delivered images are labeled as outputs |
| Many query comparisons | Directly labeled query rows with methods as distinct marks on one scale | Actual budgets, zero results, undefined precision and comparator performance |
| Component effects | Full-configuration reference plus changes across tasks, with a common change scale | Relative vs absolute values, sign, zero, and any ablation gain |
| Repeated retrieval | One mark per run; three actual pairwise overlaps beside the corresponding intent | Pairwise comparisons are dependent; observed ranges are not confidence intervals |
| Tissue-to-molecule atlas | Adjacent registered scales and measured layers; compact gallery and trend support | Geometry, crop, pixel calibration, stain and marker identity |

## Do not inherit a reference project's local mandates

Four panels, a fixed mechanism-height ratio, two hues, a specific icon count,
or mandatory statistical stars were historical choices in one project. They
are not universal rules. Select count, proportions and encodings for the current
data and user's request. Distinct modality trajectories may need distinct hues.
Real tissue and decoding masks keep their scientific colors. Add a CI or test
only when the source supports that inference.

Visual review is useful criticism, not author acceptance. Record a rejected
version as rejected even if a model reviewer praised it. When the author says
“too ugly,” make a concrete composition change and show the complete new figure;
do not answer with audit receipts or an extended defense of the previous work.
