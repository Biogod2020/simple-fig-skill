# 这次制作与返工带来的经验

这份经验来自一次科研进展汇报的实际修改。最初材料包括周报、已有单细胞
幻灯片与远程最新结果，目标是向导师汇报并请教文章范围。初版被指出不够好；
读取真正的 Claude Code 制作记录和它修改过的参考后，重做的版本得到认可。
这里只总结方法，不附原始周报、未发表图、会话文件或个人环境。

## 参考必须确实是参考

最初找到的旧目录不能证明是用户所说的 Claude Code 成品。真正的记录显示，
此前已经明确要求全亮色、清楚简单、保留 UMAP、规模和组成、先数据再结果。
对应成品采用白底、深色无衬线字、大图和直接说明。

因此，遇到“之前是怎么做的”，先找到具体版本和支持它的记录，理解用户认可
的选择。一次核对足够，不把查整个聊天历史变成每次做幻灯片的固定程序。

## 改善来自证据的组织

重做保留了听众判断所需的科学内容：数据规模、细胞组成、供体数量、实际
比较方式、外部对照和真实结果图。正文减少抽象项目术语，增加读图解释。

| 制作决策 | 为什么有用 | 如何迁移 |
| --- | --- | --- |
| 数据页展示规模、UMAP和组成 | 先知道数据是什么，才能理解分析 | 选择当前研究真正需要的数据概览 |
| 方法页展示供体分布和研究内/研究间比较 | 细胞多不代表独立样本多 | 写清统计单位和合并方法 |
| 结果页注明数据来源及筛选角色 | 看清结果是在发现、筛选还是检验 | 对每张结果图核对实际分析流程 |
| 多脑区与局部空间结果分成两页 | 比较尺度与问题不同 | 一个结果页围绕一个判断 |
| 资源条目展示真实输入与交付物 | 大规模数字有具体含义 | 用一个有来源的实例连接流程和规模 |
| 提问页给出文章范围的具体选择 | 导师可以直接反馈 | 先给当前倾向，再请教理由和优先级 |

资源规模要保留正确单位：样本、供体记录、细胞核、测量点和网格不能混用。
已有研究清单的覆盖率也不是任意新查询的检索能力。将数字放在正确问题下，
比增加一句“结果很好”更能说明进展。

## 从真实图中发现内容错误

有一页的文字说的是疾病检索，实际图却是组织图像与空间数据的配对检索。
修订时把正文和讲稿改成图中的实际需求。另一页的跨疾病斜率补上了“亚群
中位数”，避免把汇总量误读为单一总体效应。

迁移原则：每一页都要检查“标题—图—图注—讲稿”是否在回答同一个问题。
重用旧图前确认当前文字仍对应它的输入、分组和统计量。

## 实际导出暴露的问题

文字审核通过后，渲染仍发现了数值标签重叠、图注换行、图注靠近分隔线、
大数字文本框过低等问题。修订位置、文本框高度和说明长度后，再检查受影响
的页面，最后检查完整 PDF。

对原生图表，坐标、数据标签和标题未必继承周围文本的字体，应分别设置并看
导出结果。负值条形图的末端标签可能与类别名重叠；保留负数，调整标签位置。
字体文件名也未必等于实际注册的字体家族，应核对真实字形。

## 把审核和交付落到真实文件

严格本科生文字审核保持同一套标准，修订后再审。页面检查独立完成，不把
审核模型的“通过”当成已经看过全部幻灯片。交付包含演示文件、PDF、浏览器版
和逐页讲稿，主讲与讨论分别计时。

本次20分钟、16页主讲、4页备用，以及具体项目名称和期刊目标，都是任务
选择。其他汇报应按时间、证据和听众重新决定。白底大图是本次认可的设计，
不是覆盖用户明确指定模板的规则。
